# Why
Students need an immediately useful, login-free information home organized around faculties and searchable with fuzzy school, faculty, program, direction and alias matches. Teachers need broader cross-institution discovery with traceable evidence. Network-sourced material must remain a candidate until its provenance is captured and a teacher reviews and explicitly publishes it.

## What Changes
- Define public anonymous information list/detail with faculty-level organization, fuzzy search, filters and distinct student/teacher result fields.
- Define evidence-backed teacher search across institutions and disciplines without claiming exhaustive coverage.
- Define the network-source intake, provenance, extraction, deduplication, classification, conflict review, revision and publish boundary.
- Keep private student records and teacher management behind server-side identity/role checks.
- Record follow-on interface constraints for positioning feedback, consultation contact handling, privacy notice and a simulation flow awaiting reference video.

## Capabilities
### New Capabilities
- `published-information`: public information publishing/search, source review and access boundaries.

## Impact
This extends only the existing OpenSpec change and its capability delta. This change defines contracts without adding a production implementation or data migration, and does not select a collection provider or model. Follow-on positioning and simulation remain design constraints, not implemented capabilities.
