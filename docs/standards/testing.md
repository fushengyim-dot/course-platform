# 测试
来源是runtime-foundation的S1—S10。Go *_test.go按Normal/Failure/Boundary命名；前端状态测试映射S8。接口测试用httptest，依赖替身与注入时钟；不访问真实业务数据或外部业务接口。
一键命令见README，任一失败退出非零；不跳过已知失败。报告为控制台，内部保留实际输出。成功响应需同时HTTP200和code=OK；拒绝必须匹配规约码，不能只检查JSON形状。
正常探测2秒内完成，超过2秒标记，超过3秒失败；失败场景时间预算也用于防止挂死。测试独立、可随机顺序，无残留数据库依赖；Compose演练仅使用本项目测试卷。
实现后运行project-tests工作流程。故意注入反向依赖、移除拒绝判断，检查能否失败；不能发现则补检查。本机、跨会话、另一机器分别记结论，由用户负责接受修复，维护者执行本机验证。
