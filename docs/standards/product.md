# 产品设计
用户与场景、页面清单见README；基础工程包含 / 系统状态页与 /status/details 状态详情页，均复用StatusPanel并提供相互导航；未知路径404。
四状态：加载「正在检查服务状态…」；正常「服务已就绪」；错误「服务暂不可用，请稍后重试；持续失败请检查运行环境」；空「暂无状态数据，请重试」。错误/空提供重试，加载时禁止重复提交。
术语：系统状态、服务、版本、MySQL、Qdrant、重试。页面统一使用上述术语。
样式集中styles.css：间距8/16/24/32px，正文16px、次要14px、标题28px；状态组件StatusPanel复用。按钮可键盘操作，状态用aria-live；窄屏不横向溢出。
输入在提交时校验，未来表单标签须关联控件；React文本插值，不用dangerouslySetInnerHTML。违规先补状态/复用组件再验收。

健康数据为空（null或缺少data、空依赖对象）显示空状态；其他结构不合法显示错误。正常数据必须包含非空版本、可解析的UTC时间，以及恰好mysql/qdrant两个up状态。
