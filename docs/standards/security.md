# 安全开发
默认拒绝：仅GET /health、/live公开；/api/未登记全部401。新增业务接口必须服务端认证并逐资源核对归属，跨用户资源按404处理；不能只隐藏前端按钮。未来资源场景同时测试水平及功能越权。
参数类型、长度、范围、枚举走白名单；探针禁止查询参数。输出React转义；SQL参数绑定，禁止字符串拼查询。文件下载绑定已授权业务对象，不能公开原件目录。
.env不入库、不进入构建上下文；不记录请求头、查询、正文、数据库DSN、密码或原始错误；响应只暴露依赖up/down。泄露按README轮换流程处理，历史改写另授权。
依赖用途/许可登记docs/dependencies.md，锁文件入库，允许MIT/BSD/Apache-2.0、数据库驱动MPL-2.0及官方服务镜像所需许可；新增依赖需核对。每次依赖变更及发布前扫描，高/严重漏洞阻断，修复后重验；无法扫描明确记未完成。
额外外部服务本轮禁用；探测目标只能来自启动配置，不能来自请求。移除授权检查时，测试必须失败；否则补测试。
